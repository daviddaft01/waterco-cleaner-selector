# Waterco Advance Pool Cleaner Selector (AU & NZ)

Trade and staff tool for matching robotic and suction pool cleaners to a pool and its owner.

- `index.html`: start page
- `robotic.html`: robotic counter selector
- `phone.html`: on-site technician phone app (robotic)
- `range.html`: robotic range chart (printable)
- `suction.html`: suction cleaner selector (draft)

Static site, no build step. Prices are RRP in AUD; NZ to check NZ RRPs.
